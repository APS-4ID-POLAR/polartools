polartools.flyscan_gui_dichro#

Post-scan dichroism flyscan viewer.

Loads two scans (e.g. circular-right and circular-left polarizations), displays their per-image scalar maps side-by-side, and computes a (CL - CR) difference map interpolated onto a common (x, y) grid. Either polarization may be disabled, in which case only that map is drawn and the difference panel is left blank – so the viewer also covers the single-scan case.

Eiger and Vortex each get a tab, with their own ROI and their own copy of the three maps. The reduction itself – position stream to per-frame x, y and I0, detector file to per-frame ROI sum – is polartools.process_flyscan.

Settings live in a JSON file rather than in QSettings: the folder, ROIs, scan numbers and colour limits worth keeping are the ones for the analysis directory being worked in, and a second experiment should not inherit them. The file is read at startup – ./flyscan_gui_dichro.config.json unless --config names another – but nothing is written until the Autosave button in the status bar is pressed, so launching in a directory leaves no trace in it. The destination can be changed while running; neither it nor the Autosave state carries over to the next run, by design, so a session never writes somewhere forgotten. Run with:

flyscan-dichro-gui [--folder NdFeB] [--cr 490] [--cl 491] [--config FILE]
